# Aspen KB: case study

A one-page case study of Aspen KB, a personal knowledge base that AI assistants can search through the Model Context Protocol (MCP). Private notes stay local, and every retrieval change is measured.

**Read it:** https://botiejedi.github.io/aspen-kb/

The page is a single self-contained `index.html` with no build step, no trackers, and no external requests.
